# M00 — Repository skeleton

**Goal:** a repository with no features yet, but with **all the ground rules in place**: it installs, it can be checked, and it rejects architecture violations from the very first commit.

**Estimated effort:** 1–2 sessions.

**Learning objectives:**
- Understand why dependency rules between layers must be enforced by tooling rather than only written down.
- Be able to read and write import-linter contracts.

## 2. Settings (⚙️, but read it carefully)

```python
class Settings(BaseSettings):
    model_config = SettingsConfigDict(env_file=".env", env_prefix="OPSDESK_", extra="ignore")

    app_env: Literal["dev", "test", "prod"] = "dev"
    var_dir: Path = Path("var")
    log_level: Literal["DEBUG", "INFO", "WARNING", "ERROR"] = "INFO"
```
Secrets (API keys) have **no** default value and are never logged. Model settings are added in M03.

## 3. `.importlinter` (🎯 write it yourself)

The first contract, as an example:

```ini
[importlinter]
root_package = opsdesk
include_external_packages = True

[importlinter:contract:layers]
name = Harness layers
type = layers
layers =
    opsdesk.api | opsdesk.evaluation
    opsdesk.orchestration | opsdesk.workloads
    opsdesk.agents
    opsdesk.tools | opsdesk.retrieval
    opsdesk.security : opsdesk.observability : opsdesk.cost : opsdesk.resilience : opsdesk.llm : opsdesk.persistence
    opsdesk.domain
    opsdesk.core
```

> Look up the import-linter documentation to understand exactly what `|` (modules on the same layer that are **independent** of each other) and `:` (modules on the same layer that **may** import each other) mean, and confirm that your installed version supports this syntax. Write down why the infrastructure layer uses `:` while the other layers use `|`.

Add the following contracts yourself:
1. **Pure domain**: `opsdesk.domain` must not import `langchain`, `langgraph`, `fastapi`, `mcp`, `a2a` or `sqlite3` (hint: `type = forbidden`).
2. **Two RAG pipelines**: `opsdesk.api`, `opsdesk.orchestration`, `opsdesk.agents` and `opsdesk.retrieval` must not import `opsdesk.ingestion`.
3. **Ingestion uses only what it is allowed to**: `opsdesk.ingestion` must not import `opsdesk.api`, `opsdesk.orchestration`, `opsdesk.agents` or `opsdesk.tools`.

Contracts for `services/` are added in M08.

## 4. "Break the rules" exercise (🎯 required)

1. Add `import opsdesk.api` to `src/opsdesk/domain/__init__.py`.
2. Run `make arch` and read the error message.
3. Add `import langchain` to the domain (install langchain temporarily) and run it again.
4. Revert both changes. In the "Notes" section at the end of this file, record what import-linter reported, and how long such a violation could have gone unnoticed without the tool.
